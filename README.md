# Calculating DISTANCE

## Description
This program helps calulate the distance between two points using the math function. By giving the two points, we can determine the distance of thye two points.

## How to Run
1. Open the program.
2. Run the program.
3. Input the two points (x1, y1) and (x2, y2).

## Input Needed
- Value of x1
- Value of y1
- Value of x2
- Value of y2

## Sample Output

    Enter coordinate1 X:2 
    Enter coordinate1 Y:3
    Enter coordinate2 X:7
    Enter coordinate2 Y:8
    
    The Distance between the coordnates is, 7.07
